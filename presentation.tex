\begin{frame}[t]{Biological Background}
Protein formation process.
\href{https://www.youtube.com/watch?v=gG7uCskUOrA}{DNA to Protein}
\pause
\begin{itemize}
\item All Proteins required by an organism are encodied in the DNA.
\pause
\item First, RNA polymerase transcribes the part of our DNA which contains protein encoding to messenger RNA a.k.a mRNA.
\pause
\item  mRNA is post processed to get an RNA. This RNA goes outside the nucleas of a cell. RNA $\in \{A, T, C, G\}^n$ where $n \in \mathbb{I}^+$
\pause
\item  Ribosomes in the cell cytoplasm then translate RNA to an amino acide sequence. This sequence is called primary structure of a protein. The mapping can be written as - $Ribosome:\mathbb \{A, T, C, G\}^n \to \{R, N,D, C ...\}^m$
where $ m \approx \frac{n}{3}$. 
\pause
\item This amino acid sequence folds into a 3D shape depending on its sequence. This structure is called tertiary protien structure.
\end{itemize}
\end{frame}

\begin{frame}[t]{What is our problem?}
\pause
\begin{itemize}
\item In this paper the authors are trying to estimate the function
$f:\mathbb \{R, N,D, C ...\}^m \to \{Binding, NonBinding\}^m$
where $m$ is the length of any ligand binding protein.
They use CNNs.
\pause
\item This function is learnable because the binding sites are directly influenced by the tertiary protein structure which in turn depends on its primary structure.
\pause
\item Notice that $m$ is variable here!!!
\pause
\item Previous attempts to solve this problem -
SVM, Deep Neural networks, Basian classifier, Template matching (albeit high computational costs).
\item Previously methods used sliding window concept to capture residue dependencies.
\pause
\item But, nearby residues in tertiary structure may be far residues in primary structures.
\item Just increasing window size is infeasible memory and computation.
\end{itemize}
\end{frame}

\begin{frame}[t]{What is our problem? - Continued}
\begin{itemize}
\item The authors use CNNs (named DeepCSeqSite) as a universal function approximator.
\pause
\item The authors do not solve ligand specific prediction tasks.
\end{itemize}
\end{frame}

\begin{frame}[t]{Binding-Residue Prediction vs NMT}
\pause
\begin{itemize}
\item Neural Machine Translation (NMT) can be defined as a function
$g:\mathbb {\alpha}^n \to {\beta}^m$ where $\alpha,\beta$ are alphabets of 2 distinct languages and $n,m \in \mathbb{I}^+$
\pause
\item Binding-Site prediction is a specific case of NMT, where $m = n$, $\alpha$ is one of  20 amino acids and $\beta$ is $\{Binding, NonBinding\}$.
\pause 
\item The local and long distance coorelation between different ${\alpha}^n$ and ${\beta}^m$ exist in both NMT and BR prediction.
\pause
\item Hence, any solution of NMT can be used for our problem.
\pause
\item Fun fact - Ribosome is also "Translating" from DNA alphabet to Amino acid alphabet !!!
\end{itemize}
\end{frame}

\begin{frame}[t]{RNNs as a solution}
\pause
\begin{itemize}
\item As our amino acid sequence is variable in length, we could use RNNs to capture long term dependencies in the sequence.
\pause
\item There are some disadvantages
\begin{itemize}
\pause
\item The first amino acid is processed $n$ times, where n is the length of the protein. And last amino acid processed only 1 time.
\pause
\item RNNs are sequenctial in principle. Parallelizing the computation is not possible.
\end{itemize}
\end{itemize}
\pause
Solution - Convolution Neural Networks.
\begin{itemize}
\pause
\item T-CNNs can be parallelized, are 10x faster and give state of the art results.
\pause
\item In T-CNNs (DeepCSeqSite) architecture, both local and global dependencies can be captured by increassing the number of CNN layers. More on this in later slides!!
\end{itemize}
\end{frame}

\begin{frame}[t]{CNNs as a solution}
\begin{itemize}
\item Let $\alpha \in $ \{Ala, Arg, Asn ...\}. i.e Set of amino acids.
\pause
\item A protein of length $m$ is represented as ${\alpha}^m$
\pause
\item Training is done as a classifier that classifies ${\alpha}^m$ to $\{Binding, NonBinding\}^m$.
\pause
\item During training, a set of $B$ proteins is taken together.  Each protein ${\alpha}^m$ padded with $p$ dummy residues given by
$$
p =  \max_{1 \leq i \leq B} (m_i)- m
$$
to make the lengths of proteins in a single batch same.
\pause
\item The padding is removed before Loss function calculation.
\pause
\item The lengths of the protein batches can differ.
\end{itemize}
\end{frame}

\begin{frame}[t]{CNNs as a solution}
\begin{itemize}
\item Each $\alpha$ in a protein is mapped to $\mathbb{R}^{30}$. Thus a protein is mapped to a feature space $\mathbb{R}^{m \times 30}$
\pause
\item $\mathbb{R}^{30}$ are manually engineered features given by
\begin{itemize}
\item Position-Specific Score Matrix (PSSM) $\in \mathbb{R}^{20}$. This is the probilility of mutation to other amino acids. Since this  mutation is not independent,  this is calculated for the whole protein i.e $\in \mathbb{R}^{m \times 20}$.  Normalized values are calculated by
$$
y = \frac{1}{1+2^{-x}}
$$
\pause
\item Relative solvent accessibility $\in \mathbb{R}$
\pause
\item Secondary Structure i.e \{alpha-helix, beta-strand, coil\} $\in \mathbb{R}^3$
\pause
\item Dihedral angle $\in \mathbb{R}^2$
\pause
\item Residue type $\in \mathbb{R}$. Given by
$r = \frac{type}{21}; type \in [0,20], \mathbb{I}+$.\\
Here $0$ means dummy residue, $[1-20]$ represents\\ other residues.
\end{itemize}
\end{itemize}
\end{frame}

\begin{frame}[t]{CNNs as a solution}
\begin{itemize}
\item $\mathbb{R}^{30}$ Continued...
\begin{itemize}
\item Conservation scores $\in \mathbb{R}^2$
\pause
\item Position embeddings $\in \mathbb{R}$. Given by $PE_i = \frac{i}{m}$ for $i^{th}$ residue.
\end{itemize}
\end{itemize}
\end{frame}
