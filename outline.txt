Method outline
Each residue in the protein sequence is a potential binding residue, hence we must have some
features engineered for each residue of the protein. Hence after engineering the input features,
we have 30 features/residue in a protein. That gives us a feature map of L * 30 feature map.

General method
Take 2000 sequences with corresponding label residues for training.
Divide the sequences into say 100 sequence batches
Each batch should be of same length. If the sequences in the batch are differing in length pad them
Across batches the length of the sequences can be different.
We create an input volume to our convolution neural network - (30 * batch length * batch size) i.e input feature map

Effective input field
1D convolution
And there is considerable overlap hence the input field does not grow exponentially

The Basic block
After producing m*1*2c output channel in the initial convolution,
We apply the following transformation to get R^{m*1*c} volume
It produces 2c channels in each step because after the creation of an output of
each step we have to do a gated transform
a * sigmoid(b) which returns the input channels to c.
After getting R^{m*1*c} output channels we apply for 2c kernels of volume R^{m*1*c}
to get an output volume of R^{m*1*2c} which again in the input of to the next basic block.
Like this there are N basic blocks.
What is interesting to note is that at each step, each residue is represented by a volume of R^{1*1*2c} features at a given abstract level of represtation. Hence when we apply a kernel, it is important
that the whole feature volume of every residue considered by the kernel is taken into account.
Only then can we successfully build higher abstractions based on extracted features at a lower abstraction.


The decoder network:
First a 1*1*2c kernel is employed to get c output channels
Again 1*1*c kernels is employed to get 2 outputs (for each residue)
Afterwards a softmax is applied weather it is positive or negative. A 2 way softmax the predicts the probability of each residue being a positive or negative sample.
